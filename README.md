# DSP Acoustic Similarity

Метрика акустического сходства: описание **тракта записи** (сведение, шум,
помещение) отдельно от голоса. Без обучаемых весов: только DSP-статистики
лог-мела и временные признаки реверберации плюс эталонная z-нормировка
(`acoustic_norm.npz`).

Зачем: speaker similarity на готовых эмбеддерах наполовину меряет запись, а не
тембр. CAM++ в 64 % случаев кладёт двух **разных людей, записанных одним
трактом**, ближе, чем пару с разными трактами. Поэтому TTS, который лучше
скопировал акустику донора, выигрывает по speaker similarity, даже если голос у
него хуже. Эта метрика меряет как раз ту ось.

## Использование

```bash
pip install -r requirements.txt
```

```python
from acoustic_metric import AcousticMetric

m = AcousticMetric(device="cuda:0")      # или "cpu"
a, b = m.encode("ref.wav"), m.encode("synth.wav")
spec, room = m.similarity_parts(a, b)    # похоже сведение / похоже помещение
print(m.similarity(a, b))                # среднее из двух
```

`encode` принимает путь к файлу или моно-волну 16 кГц (numpy / torch) и
возвращает вектор из 221 числа: 133 спектральных + 88 временных.

Длина записи: с 3 секунд цифры стабильны, короче 2 секунд метрике верить не
стоит.

## Две оси, а не одна

| ось | размерность | что опознаёт |
|---|---|---|
| спектральная | 133 | подложку, эквализацию, полосу, уровень шума — сведение |
| временная | 88 | скорость спада уровня, автокорреляцию огибающей, модуляции — помещение |

Оси коррелируют на 0.53 и на трети пар расходятся. Реверберация — это скорость
затухания, и в усреднённых по времени статистиках её нет физически, поэтому
«похожа ли акустика» одним числом смешивает комнату с микшером.

Шкала спектральной оси читается напрямую: у двух клипов одного фильма медиана
косинуса +0.63 (квартили +0.39..+0.79), у клипов разных фильмов — 0.00
(−0.33..+0.33).

## Главные цифры

AUC косинусной близости. **Тракт** — один тракт, разные дикторы (хотим высоко);
**диктор** — один диктор, разные тракты (хотим низко, в идеале 0.5).

| | тракт | диктор |
|---|---|---|
| **эта метрика** | **0.911** | **0.566** |
| CAM++ | 0.644 | 0.896 |
| ReDimNet2-B6 | 0.578 | 0.933 |

Различение помещения на реальных импульсных характеристиках RWCP / AIR / RVB2014:

| | комната | утечка диктора |
|---|---|---|
| спектр (133) | 0.659 | 0.604 |
| **время (88)** | **0.713** | **0.553** |

Обучаемые варианты (восемь постановок, от дистилляции до свёртки по
спектрограмме) сырые статистики на реальных данных не превзошли, поэтому их
здесь нет.
